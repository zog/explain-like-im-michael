# explain-like-im-michael

A Claude Code skill that explains technical issues (incidents, bugs, errors, changes) to a non-technical person with minimal jargon: bottom line first, what happened, what it means for them, what's next.

Trigger it by saying "explain to me like I'm Michael", or by asking for a plain-language explanation of a technical issue.

## Install

```sh
git clone <this repo> ~/src/explain-like-im-michael
ln -s ~/src/explain-like-im-michael/skills/explain-like-im-michael ~/.claude/skills/explain-like-im-michael
```
